# Documentation

## Meaning

This map routes readers and maintainers to xkcd Reading Tracker's durable product, system, data, development, and evidence homes. It exists because the repository now has several maintained subjects and dated reference records; it is navigation, not another introduction or Work queue.

## Product And Direction

- [Product Vision](VISION.md) — provisional durable purpose, intended reader experience, and product boundaries.
- [Direction](DIRECTION.md) — provisional current outcome, near-term cuts, and explicit not-now context while Git temporarily carries direction.
- [Decisions](DECISIONS.md) — settled choices and the reasons or rejected alternatives that still matter.

## System And Data

- [Architecture](ARCHITECTURE.md) — current runtime components, flows, and integration boundaries.
- [Data Model](DATA-MODEL.md) — persisted records, invariants, schema, backups, import, and reset semantics.
- [Privacy and Data](PRIVACY-AND-DATA.md) — reader data, storage, third parties, export, and deletion.
- [Security](SECURITY.md) — permissions, trust boundaries, accepted limits, and private vulnerability reporting.
- [Project Map](PROJECT-MAP.md) — repository layout and code entry points.

## Development And Release

- [Development](DEVELOPMENT.md) — prerequisites, commands, generated artifacts, and ordinary local paths.
- [Manual QA](manual-qa.md) — browser-only release checks that Node cannot prove.
- [Releasing](RELEASING.md) — version, package, Chrome, Store, and release boundaries.

## Reference Evidence

Dated, append-by-design audits and provenance live under `reference/`. They preserve what was observed and judged at a named time; current product direction and active Work do not live there.
